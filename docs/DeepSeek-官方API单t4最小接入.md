# DeepSeek API 单t4能力筛选：最小离线接入任务

用户已授权使用实验室提供的DeepSeek API，先跑一次原始t4，不带后验规格提醒，不启动完整R/E。不新增部署/付费操作授权步骤；但实验室实际base_url、wire模型名、密钥文件路径尚待用户提供，不能假定第三方网关就是官方API。

## 范围

复用scripts/ae_01_local_t4_probe.py的已核r3任务构造、19工具、原生用户对话链和确定性订单诊断。新增独立云筛选入口/传输适配和定向测试；旧回环入口及云冻结profile不放宽，不覆盖原脚本或旧交付。不要复制重写整套工具/模拟器，先提出最小复用接口再实现。

API身份由用户实际声明固定。官方候选base=https://api.deepseek.com，model=deepseek-flash（文档当前对应V4.1-Flash）；实验室网关需以其实际文档/模型目录另核，不猜映射。密钥仅run时从指定0600文件读取，不输出、不进交付；plan零网络。非思考模式使用该端点明确支持的字段，不能沿用vLLM chat_template_kwargs。记录模式；如字段不支持停止，不静默回退。

仅单次t4，Agent<=12、用户<=4、合计<=16；输出预留2048/4096、temperature=0、串行、不做传输重试、每请求180秒沿用；非200/空/length/不确定均停止。用户模拟也走同一预算与明确出口。工具上限26214、原任务/提示/oracle不改，原始规格提醒副本不使用。固定新目录。

云端不假定存在/tokenize或models.max_model_len。容量声明与已测状态分开：本轮是短任务能力筛选，不是1M容量验证，不改正式RUN verified门。不要冒用Qwen tokenizer、bytes/4或把字符数称为token；如需本地计数必须使用匹配且可核的DeepSeek资产/接口，否则明确未知、使用独立记录的请求字节预算作为成本保护而非精确容量保证。具体预算须在plan里固定并由Codex核对后部署，不自动填verified。首次测试以原任务规模为限，不发百万token探针。

保存每角色实际请求（不含Authorization）、原始响应、usage/费用字段（若无则未知）、工具回包/订单、实际URL/model/模式/代码摘要。保持原生对话状态与角色翻转，不能再次另写简化用户模拟器。模型别名可能随服务更新，不声称已固定权重版本。

定向只测：真实HTTP构造及认证脱敏；Agent和用户出口/预算一致；原始t4提示和工具不变；200真实native create/pay诊断；401/429/超时一次即停；plan缺密钥零发送；旧本地入口仍拒绝公网。不要跑全仓或旧交付全集。新交付目录在任何写入前若已存在即拒绝。
